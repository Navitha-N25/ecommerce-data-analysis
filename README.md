# E-commerce Data Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using Python to identify revenue trends and top-performing countries.

## Project Objectives
- Load and sample 10% of the dataset.
- Clean the dataset by handling missing values.
- Correct data types and convert `InvoiceDate` to datetime.
- Remove returned transactions and free items.
- Calculate revenue using Quantity × UnitPrice.
- Identify the top 10 countries by total revenue.
- Visualize revenue performance using a bar chart.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Load the UCI Online Retail dataset.
2. Randomly sample 10% of the rows.
3. Clean and prepare the data.
4. Convert invoice dates into datetime format.
5. Calculate revenue for each transaction.
6. Aggregate revenue by country.
7. Plot the top 10 countries by revenue.

## Key Deliverable
A bar chart displaying the top 10 countries by total revenue.
